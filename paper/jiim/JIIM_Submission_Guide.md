# Springer *Journal of Imaging Informatics in Medicine (JIIM)* Submission Guide

## 1. Before You Submit (Files Ready in `paper/jiim/`)
- **Title Page (Separate Unblinded File):** `paper/jiim/JIIM_Title_Page.pdf` (and `.tex`)
- **Blinded Main Manuscript (`0` author/institution leaks):** `paper/jiim/JIIM_Blinded_Manuscript.pdf` (and `.tex`)
- **High-Resolution Figures (300 DPI PNGs):** `paper/jiim/figures/fig1_architecture_pipeline.png` .. `fig5_platif_186_cohort.png`
- **Bibliography:** `paper/jiim/references.bib` (`13/13` verified citations)
- **Automated Audit Report:** `paper/jiim/agent_review_report.md`

## 2. How to Publish for **$0** (Zero Fee) on Editorial Manager
1. Log in / register at **Springer `JIIM` (`link.springer.com/journal/10278` -> Submit manuscript -> Editorial Manager)**.
2. **Article Type:** `Original Paper` (or `Software / Technical Note` if offered).
3. **Upload Files Individually:**
   - **Title Page:** Upload `JIIM_Title_Page.pdf` (or `.tex`)
   - **Manuscript (Blinded):** Upload `JIIM_Blinded_Manuscript.pdf` (or `.tex`)
   - **Figures:** Upload `fig1_architecture_pipeline.png` through `fig5_platif_186_cohort.png` if requested separately
4. **Publishing Model Selection (CRITICAL FOR `$0` FEE):**
   - Choose **`Subscription` (Traditional publishing model)** — **$0 APC** (`₹0`).
   - Do **not** select Gold Open Access unless institutional funding covers it (`~$3,000+`). Your earlier Zenodo preprint (`10.5281/zenodo.24455205`) already serves as your open-access reader copy!
5. **Companion JOSS Paper (Optional Later):** Once `JIIM` is under review or accepted, add `paper.md` + `CONTRIBUTING.md` + expanded unit tests in the root repo and submit the software citation paper (`$0` Diamond OA) to **`JOSS`**, citing the `JIIM` study.
